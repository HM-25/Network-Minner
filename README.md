# NetworkMiner

Study notes on **NetworkMiner**, an open-source Network Forensic Analysis Tool (NFAT) by Netresec. It extracts hosts, sessions, files, credentials and other artifacts from live traffic or PCAP files.

## Typical use cases

- Building a host inventory from a PCAP
- Extracting transferred files and images
- Spotting cleartext credentials and suspicious sessions
- Supporting incident response alongside Wireshark and Zeek
